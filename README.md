## 📲 Como Baixar e Instalar

Esta é a nossa **Central Oficial de Distribuição de APKs**. Aqui você encontra sempre a versão mais recente, estável e otimizada do GhostTap.

1. Vá até a aba **[Releases](../../releases/latest)** deste repositório.
2. Na seção *Assets*, clique no arquivo **`GhostTap-vX.X.apk`** para iniciar o download direto no seu celular.
3. Instale o aplicativo normalmente. *(Caso o seu Android exiba um aviso de segurança por ser um app externo à Play Store, selecione "Instalar assim mesmo" — o GhostTap é 100% seguro).*

## 🛠️ Compatibilidade & Tecnologias

* **Android Suportado:** Android 8.0 até o Android 14+ (One UI Core, Motorola e demais fabricantes).
* **Motor de Injeção:** Tecnologia avançada via **Binder IPC (AIDL)** com latência inferior a 2ms, garantindo cliques instantâneos sem travamentos.
* **Modo 4G / 5G Blindado:** Desenvolvido para rodar perfeitamente na rua, sem perder estabilidade ao transicionar de rede.
